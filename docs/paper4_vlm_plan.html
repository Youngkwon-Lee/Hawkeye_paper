6. 다음 의사결정 게이트 (2026 H2)

Gate 1 — protocol lock
데이터 사용 승인·피험자 split·영상 품질 기준·출력 JSON schema·문헌 검색식을 고정한다.
Gate 2 — pilot
고정된 소규모 validation에서 native-video, frame, pose+kinematic 경로와 quality-gated abstention을 비교한다.
Gate 3 — evidence review
임상의 블라인드 검수로 timestamp–rubric 적합성을 확인하고, 통과한 rationale만 student 학습 후보로 승격한다.
Gate 4 — locked test
피험자 단위 고정 test에서 QWK/Spearman, CI, subgroup error, coverage를 보고한다.
Gate 5 — external validation
허용된 외부 데이터 또는 승인된 임상 코호트에서 카메라·해상도·태스크 변화에 대한 일반화를 검증한다.
Submission decision
사전등록한 성공·안전성 기준을 만족할 때만 목표 저널·학회 일정과 함께 투고 결정을 갱신한다.
