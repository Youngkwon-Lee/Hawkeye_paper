1. 스켈레톤 기반 접근법 (2D/3D)

연구량: 25편 이상으로 가장 포화된 영역. 대부분 단일 데이터셋·단일 태스크 평가.
주요 방법론: MediaPipe/OpenPose 2D 추출 → ST-GCN/LSTM (시계열). 트렌드: 2D → 3D 스켈레톤 리프팅(MotionBERT)으로 시점 불변 특징 확보.

2. SMPL 기반 접근법 (3D 신체 메시)

연구량: 부상 중인 영역, PD 운동 평가 약 5편.
결론: SMPL 메시/표면 정보는 UPDRS 채점에 불필요. 3D 스켈레톤 관절(MotionBERT)만으로 충분 — 경량, 빠른 추론, 시점 불변, 모든 UPDRS 태스크에 최적.
CARE-PD도 실제로는 SMPL joints(관절)만 사용, mesh 불사용.

3. RGB 비디오 접근법 및 VFM

RGB CNN (전통): I3D, C3D, SlowFast 등. 소규모 단일 기관 데이터 의존.
VFM: VideoMAE, V-JEPA, VideoPrism, TimeSformer. PD 이진 분류 1편(arXiv:2602.13507), UPDRS 0-4 채점은 0편.

4. VLM 접근법 (비전-언어 모델)

연구량: PD 운동 UPDRS 채점 0편 (2026.02 기준, 세계 최초 연구 기회)
활용 모델: Gemini 2.5 Pro (네이티브 비디오), GPT-4.1, Qwen3-VL-8B (오픈소스).
핵심 장점: 임상 근거 설명 생성 가능 (기존 black-box 모델과 차별화).
기존 논문 0편 = 완전한 퍼스트무버 우위
  • 임상 추론: VLM은 점수 부여 이유를 자연어로 설명 가능
  • 멀티태스크: 동일 모델로 4개 태스크를 재학습 없이 처리
  • 임상 수용성: 설명 가능한 AI는 의료 도입에 핵심

포화 영역 회피
