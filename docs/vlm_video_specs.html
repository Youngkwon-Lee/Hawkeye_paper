VLM video evaluation protocol

공급사 모델명·가격표가 아니라, PD 운동 채점에서 실제로 비교 가능한 비디오 입력 방식·시간 근거·품질 보류 규칙을 고정합니다.

중요: 모델·할당량·가격·지원 형식은 자주 바뀝니다. 공개 결과에는 정적 가격을 인용하지 않고, 각 실행의 모델 ID / API 버전 / 리전 / 호출일 / 입력 샘플링 / 토큰·비용 로그를 함께 보존합니다.

비교 대상은 “모델”보다 “입력 경로”

native-video candidate

상용 네이티브 비디오

비디오·오디오를 직접 해석할 수 있는 공급사 모델을 후보로 삼습니다. 최종 모델 ID와 파일 제한은 실행 당일 공식 문서로 고정합니다.

frame baseline

프레임 시퀀스

동일한 20초 구간에서 균일 샘플링한 이미지와 프롬프트를 입력하는 비교 기준선입니다. 시간 정보 손실을 결과 해석에 명시합니다.

local student

로컬 오픈 VLM

라이선스가 허용된 오픈 모델에만 LoRA/DoRA 등 학습을 적용합니다. 비디오 디코더, 프레임 수, seed와 체크포인트를 재현 로그에 기록합니다.

고정 평가 파이프라인

1. 원본 영상
2. 품질 게이트
3. 3개 입력 경로
4. 근거 검수
5. 고정 test 평가
단계고정 사항산출물
영상 품질 게이트시점, 프레임률·해상도, 가림, 다인 장면, 동작 구간을 기록pass / review / abstain 및 사유
입력 구성native video, 균일 프레임, pose+kinematic 보조 입력을 같은 subject split에서 비교입력 manifest와 SHA-256
모델 출력점수 0–4, confidence, 근거 timestamp, 근거 문장, 보류 여부를 구조화해 요청JSON schema validation log
임상 검수rationale의 문장 유창성이 아니라 근거 구간·rubric 일치성을 독립 검수근거 적합 / 부적합 / 불충분
고정 평가피험자 단위 test lock; 프롬프트·모델 선택은 validation에서만 결정모델 카드와 재현 패키지

평가·안전성 기준

순서형 성능

Primary: QWK, Spearman ρ. Secondary: MAE, macro-MAE, exact/OBO accuracy. 모든 수치는 task·score·dataset별로 분해하고 subject-level bootstrap 95% CI를 병기합니다.

시간·근거 충실도

근거 timestamp가 실제 동작 구간을 가리키는지, 설명이 MDS-UPDRS rubric과 일치하는지를 임상의 블라인드 검수로 평가합니다.

임상 경계

이 시스템은 연구용 의사결정 보조 후보입니다. 품질 미달·저신뢰 출력은 점수를 강제하지 않고 보류하며, 단독 진단·치료 판단을 주장하지 않습니다.
